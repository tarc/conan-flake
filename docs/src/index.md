# conan-flake

`conan-flake` is a pure Nix module that bridges [Nix](https://nixos.org/) and
the [Conan C/C++ package manager](https://conan.io/): Conan profiles, remotes
and tool requirements are declared as Nix options instead of hand-written Conan
configuration files.
